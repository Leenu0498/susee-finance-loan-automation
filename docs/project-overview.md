# Susee Finance Loan Application Automation

## Project Overview

A digital loan application workflow developed to simplify and automate the loan entry process for finance operations.

The solution was designed to replace manual loan-entry processes with a structured application workflow using Zoho Creator and Deluge.

## Business Problem

The existing loan application process involved manual data entry and repetitive operational tasks.

This created challenges such as:

- Manual loan number generation
- Repetitive data entry
- Risk of incorrect loan sequences
- Manual date calculations
- Limited application status control
- Manual communication of generated loan numbers

## Solution

I developed a structured loan application system using:

- Zoho Creator
- Deluge
- Workflow Automation
- Form Validation
- Sequence Management
- Automated Email Notifications

## Key Features

- Digital loan application form
- Loan-type-based loan number generation
- Automated sequence management
- First EMI date calculation
- Maturity date calculation
- Application status control
- Form validation
- Automated loan number email notification
- Structured loan application reporting
