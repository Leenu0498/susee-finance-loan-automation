# Susee Finance Loan Application Automation

> A low-code loan application workflow designed to automate loan entry, loan number generation, EMI date calculation and executive notifications.

---

## 📌 Project Overview

This project demonstrates the design and automation of a digital loan application workflow using **Zoho Creator and Deluge**.

The solution was developed to reduce manual processing in loan operations and provide a structured workflow for branch executives.

---

## 🎯 Business Problem

The traditional loan-entry process involved several manual activities:

- Manual loan application entry
- Manual loan number generation
- Risk of incorrect loan sequences
- Manual EMI date calculation
- Manual maturity date calculation
- Limited control over application availability
- Manual communication of generated loan numbers

These processes could lead to repetitive work, inconsistencies and delays.

---

## 💡 Solution

I designed a centralized loan application workflow using **Zoho Creator** and **Deluge**.

The system automates the major steps from application submission to loan number generation and executive notification.

### Workflow

```text
Executive
    ↓
Loan Application Form
    ↓
Form Validation
    ↓
System Status Check
    ↓
Loan Number Generation
    ↓
Sequence Management
    ↓
First EMI Date Calculation
    ↓
Maturity Date Calculation
    ↓
Loan Record Saved
    ↓
Email Notification
    ↓
Executive Receives Loan Number
